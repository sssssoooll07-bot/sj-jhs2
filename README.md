# 신정개발 연구소 현황 (RLMS Lite)

엑셀 마스터 데이터를 **브라우저에서 열어** 보는 경량 조회 서비스.

- 회사: [신정개발](https://sjdevel.com/)
- 원본 시스템: RLMS (연구비·협약·특허·법정의무·지원사업 통합 관리, 별도 저장소)

## 🔒 보안 구조 (중요)

기업 데이터(과제·특허·연구원·인증)는 민감 정보이므로 **저장소·서버에 올라가지 않는다.**

```
사용자 PC의 엑셀 파일
   → 브라우저에서 파일 선택/드래그
   → 브라우저 안에서만 파싱·표시 (서버 전송 없음)
   → (선택) "이 브라우저에 기억" — 이 기기의 localStorage에만 보관
```

- **어떤 엑셀 파일도 커밋되지 않는다** — `.gitignore`가 `*.xlsx`, `*.xls`, `*.xlsm`, `*.csv`, `data/`를 차단한다.
- 서버에는 데이터 API가 없다. 배포된 사이트는 껍데기(뷰어)일 뿐, 데이터는 각 사용자의 파일에서 온다.
- `/api/local-file`은 로컬 개발 편의 기능으로, Vercel(운영)에서는 항상 404다.
- 공용 PC에서는 "이 브라우저에 기억"을 끄고, 사용 후 상단 "데이터 제거"를 누르면 된다.

## 사용 방법

1. 배포된 사이트 접속 (예: https://sj-jhs2.vercel.app)
2. `신정개발_RLMS_마스터데이터.xlsx`를 드래그하거나 파일 선택
3. 대시보드·과제·특허·공고·법정의무·인증·연구원 화면에서 조회
4. 데이터가 바뀌면 엑셀을 수정하고 다시 불러온다 (커밋·업로드 불필요)

## 화면

| 경로 | 내용 |
| --- | --- |
| `/` | 대시보드 — 진행중 과제·특허·마감 임박(공고/법정의무/인증 갱신)·참여율 경고·데이터 품질 검증 |
| `/projects` | 연구과제·지원사업 목록 + 다년차(차수/참여기관/입금) 상세, 차수합계=총액 자동 검증 |
| `/patents` | 특허 — 등록완료(등록일 순)/출원중(출원일 순), PCT·연계과제 |
| `/funding` | 지원사업 공고 + 출처 바로가기(JNTP·SMTECH) |
| `/compliance` | 법정의무 D-day + 연구원별 총 참여율(100% 초과 경고) |
| `/certifications` | 인증·면허·표창 + 갱신 D-day |
| `/researchers` | 연구원 로스터(개인정보 최소수집·연구자번호 마스킹) |

## 엑셀 입력 규칙

- 금액은 **천원 단위** 숫자만, 날짜는 `YYYY-MM-DD`.
- 구분값은 엑셀 드롭다운([코드표] 시트) 사용. **시트명·열 순서는 변경 금지** — 서비스가 헤더명으로 파싱한다.
- 자동 계산 열(차수합계·검증·계)은 입력하지 않는다 — 웹에서도 다시 계산해 검증한다.
- 범위 제외: 산학협력단 지원사업, 산학융합지구 과제, 고용·현장안전 보조금(경영지원·안전팀 소관).

## 로컬 실행

```bash
npm install
npm run dev   # http://localhost:3100
```

개발 머신에서는 `data/` 폴더(gitignore 대상)에 엑셀을 두면 자동으로 불러온다.

## Vercel 배포

GitHub 저장소를 Vercel에 연결하면 push마다 자동 배포된다. 환경변수·DB 불필요.
데이터는 저장소에 없으므로 **배포를 다시 해도 데이터가 노출될 일이 없다.**
